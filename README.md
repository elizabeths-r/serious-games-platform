# Serious Games Platform

Interactive serious games platform developed with Python, Flask, and JavaScript for human-robot interaction applications. The platform supports educational and therapeutic serious games, user interaction tracking, and integration with robotic systems.

## Features

- Interactive serious games
- Web-based user interface
- Robot integration support
- User activity tracking and metrics collection
- Database-driven storage of game sessions and performance data

## Technologies

- Python
- Flask
- JavaScript
- HTML/CSS
- SQLite

## Project Structure

- `templates/` - HTML pages
- `static/` - CSS, JavaScript, and multimedia resources
- `models.py` - Database models
- `game_metrics.db` - Game metrics database
- `acciones.py` - Application logic
